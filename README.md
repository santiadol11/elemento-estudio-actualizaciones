# ELEMENTO Estudio — actualizaciones

Archivos de distribución que descarga el botón **Actualizar** de ELEMENTO Estudio (desde la versión 1.46).
No contiene código fuente.

- `latest.json`: la última versión publicada.
- `versiones/<versión>/ELEMENTO_Estudio.html.gz`: el programa de cada versión.
- `historial.json`: todas las versiones publicadas.
